# Rounded app typography

Nunito is bundled locally so typography works offline. Font source: https://github.com/google/fonts/tree/main/ofl/nunito . Original variable font downloaded from https://raw.githubusercontent.com/google/fonts/main/ofl/nunito/Nunito%5Bwght%5D.ttf .

The Open Font License is bundled at `android/app/src/main/assets/licenses/nunito-ofl.txt`. Static weights500,600,700,800,900 were instantiated from the original variable font, without outline or design changes, for predictable Android rendering. The original source is retained here as `nunito_variable.ttf`.
